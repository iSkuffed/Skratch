Native local playback

Working

Rust desktop app with a headless mpv player. MP4 files play audio without video rendering.

Watched folders and library

Working

Folders persist across restarts and changes are watched. Browse albums, artists, or tracks; search and sort the library.

Artwork and tag editing

Working

Reads embedded or folder artwork. Edit supported tags and rename files in place; existing destination files are not overwritten.

Playback controls and restore

Working

Shuffle, repeat, queue and position restore, plus desktop media controls through MPRIS.

Initial validation and resource sample

Working

26 tests passed. The original player-only run with seven generated tracks used 53 MiB app PSS idle and about 111 MiB app-plus-mpv PSS during playback. Large-library use has not been measured.

yt-dlp download panel

Working

One URL downloads one item as original audio or MP3 to a chosen source destination. Metadata and thumbnails are kept where available. The panel reports progress and supports cancellation; partial downloads stay staged until completion.
